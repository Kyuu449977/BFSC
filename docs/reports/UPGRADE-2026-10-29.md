## Giới hạn và chạy lại

Chưa kiểm thử trên iPhone/Android vật lý hoặc production. WebKit desktop là bằng chứng engine, không phải chứng nhận Safari iOS và bàn phím thật. Không đổi dữ liệu backend/data hoặc sổ private.

```sh
python -B build_public.py
node --test tests/*.test.cjs
python -B -m unittest discover -s tests -p "test_*.py"
node tests/upgrade-browser.cjs
node tests/upgrade-features-browser.cjs
node tests/upgrade-pwa-browser.cjs
node tests/upgrade-settings-browser.cjs
node tests/responsive-upgrade-browser.cjs
```

Đặt BFSC_TEST_ENGINE=webkit để chạy acceptance với WebKit. Cần engine Playwright đã cài. Báo cáo trước nâng cấp ở artifacts/project-understanding-2026-10-29 và diff source/public baseline ở artifacts/platform-baseline.
