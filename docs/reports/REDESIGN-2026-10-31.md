# Ăn gì đây — discovery interface redesign

Implemented the approved quick-selection discovery direction locally. No hosting
deployment. The design contract is recorded in the root DESIGN.md.

## Delivered behavior

- Shared neutral light/dark surfaces, system green accents, local Be Vietnam Pro,
  consistent control/card geometry and 44px minimum action targets. Saved accent
  and appearance preferences remain supported; automatic appearance is retained.
- Desktop choose/feature split; on phones the category and draw actions precede
  the image. One primary single-draw action, secondary triple/combo, compact custom
  wheel and collapsible budget/preferences. Six home previews; twelve menu items.
- Shared desktop navigation and mobile bottom navigation. Collection navigates to
  the menu collection route. Existing URL filters, no-reload pagination, native
  modified link clicks and Back/Forward remain intact.
- Eight tools grouped in one settings dialog. Tool dialogs return focus correctly.
  Custom select lists and tooltips are attached to their owning modal so they
  remain usable in the native dialog top layer.
- Consistent result, picker, contribution, theme, language, timezone, sharing and
  install dialogs. Result photo/name precede cost details; a fixed Maps action is
  primary. One result opens its Maps link; multiple results scroll to individual
  Maps links. Input survives closing a select; no test contributions were posted.
- Reused picker rows/search, independent result/picker/form scroll areas, reserved
  photo ratios, reduced motion and the existing low-end roulette are retained.
- Restyled privacy/terms/credits through shared tokens. Five-language settings,
  section and action copy. Native checkbox semantics are retained.
- Removed decorative vines/glows and the old global CSS layering. Replaced six
  stylesheet scopes; publish order now places responsive layout after components.
  CSS source size: 127,402 -> 36,427 bytes before the last minor copy-only changes
  (71.4% smaller). No new runtime dependency or remote font.
- Monetag and three Adsterra units retain their keys/dimensions. Units reserve
  space outside primary controls; pagination does not remount them. Cache v39.

## Preservation and scope

No changes to backend contracts, dish data/IDs/prices, selection algorithms,
persisted storage keys or provider credentials. Catalog remains 350 built-ins,
including 130 Vietnamese entries. Prior reviewed drink-image hashes and all
three banner keys were checked unchanged. The removed introduction panel stays
removed. Generated public files are rebuilt from source.

## Performance observation and limitations

Same repeated-roulette harness: Edge/Chromium, sixfold CPU slowdown, reported
4GB/four cores, thirty runs per variant. Long tasks totaled 1,207ms before and
720ms after (40.3% lower). End-of-run DOM counters: 2,696 -> 2,482 nodes and
277 -> 265 event listeners. Every run left zero live reel cards after release;
both runs reported no page errors.

This is a bounded local animation harness, not a real-phone benchmark or a
measurement of live third-party advertisements. Hardware Safari/Android,
production hosting and actual provider fill/popups were not certified.
