# Strict Architect & Spec-Driven Coder (`strict-architect-coder`)

An Agent Skill (`SKILL.md`) for Antigravity, Claude Code, Cursor, and GitHub Copilot that enforces:
1. **Scope Isolation & Context Mapping** (Read before write, strict UI vs. Backend boundaries)
2. **Bite-Sized Implementation Blueprints** (Atomic micro-tasks before coding)
3. **Disciplined Execution & Anti-Hang Guardrails** (Surgical edits, no hanging background CLI benchmarks)
4. **Pre-Completion Verification Gates** (Type check, scope audit, and root-cause summary)

---

```powershell

```
